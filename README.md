# GoAdventure
A simple go Text Adventure game for school, similar to [TextAdventure](https://github.com/Priestytheplushie/TextAdventure)

## QuickStart 
### Prerequesites
- Install [Go](https://go.dev/doc/install)

```bash 
git clone https://github.com/Priestytheplushie/GoAdventure
cd GoAdventure
go game.go
```

## How to Play 
- Follow the instructions on screen
- Make choices with number inputs
- Do not stall, or you lose
- Get to the end, make smart decisons
